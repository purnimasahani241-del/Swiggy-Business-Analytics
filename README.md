Swiggy Business Analytics Using MySQL

Project Overview:

This project analyzes Swiggy order data using SQL to understand revenue, customer spending, city-wise performance, and popular order categories.

Tools Used:

MySQL
SQL
GitHub
Database

Table: Orders

Columns: order_id, customer_name, city, category, amount

Business Objectives:

Calculate total orders and revenue.
Find the average order value.
Identify the highest-revenue city.
Analyze popular categories.
Rank customers by total spending.
Identify high-value orders.
SQL Concepts Used
COUNT(), SUM(), AVG()
GROUP BY and ORDER BY
Subqueries
CASE WHEN
RANK(), ROW_NUMBER(), DENSE_RANK()
Aggregate functions

Project Files:

Swiggy_Analysis.sql — SQL queries used for analysis.
